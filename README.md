# Музей детства

Рабочая версия проекта НЭН × VK Видео: входная история, два комментария и прогулка по пяти эпохам. Шрифт Onest, брендовый синий ВК, объёмные облака и предметы.

На главной фон светлеет при прокрутке, большой логотип переезжает в закреплённую шапку, облака и текст двигаются с небольшим параллаксом. Поддерживается `prefers-reduced-motion`.

В музее прокрутка двигает камеру по коридору. Эпохи выбираются нижним таб-баром. Вступление открывается при входе в эпоху и закрывается первым скроллом. Нажатие на предмет открывает полный текст; закрытие возвращает в ту же точку. Доступны все55 предметов, пять историй «Спокушек» и комментарии экскурсоводов.

## Локальный запуск

```sh
python3 -m http.server 8790 --bind 127.0.0.1
```

Открыть `http://127.0.0.1:8790/`. Сборка и зависимости не нужны.

Проверки: `npm test` (Node22+ и Python3). GitHub Pages публикует корень ветки `codex/launch`; `.nojekyll` отключает обработку Jekyll.
